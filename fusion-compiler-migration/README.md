# Fusion Compiler 迁移知识站

HV2M23 项目 DC(Design Compiler)→ Synopsys Fusion Compiler 迁移过程的静态知识站点。

## 页面导航

| 页面 | 内容 |
|------|------|
| `index.html` | 首页:系列导航 + 最新进展 |
| `evaluation.html` | FC 引入评估实录:范围决策、内网踩坑、license 排查、DC→FC 差异对照 |
| `handoff-guide.html` | 服务器回传上手指引 |
| `bringup-log.html` | FC 首跑排障实录:CMD-005 / LM-010 / LEFR-012 / LM-091 / DES-203 五道关卡 |
| `help-request.html` | 外部求助清单(IT / Foundry FAE / CAD) |
| `fc-sop.html` | 换项目快速启动手册:输入契约、18 文件体系、SOP 七步、踩坑地图 |
| `lec-noneq-case.html` | FC vs DC 行为差异攻坚实录:NONEQ 282 点四刀战记 + 约束移植 |
| `guide-library.html` | EDA 手册库导读:86 份 PDF 逐本导读、8 阶段阅读路线、精读主线 10 本 |

## EDA 手册库

`UserGuide/` 目录(86 份工具手册与教材,约 663MB)体量过大,单独托管在
[UserGuide](https://github.com/ymzhuuuuufz0313l/UserGuide) 仓库,
本仓库通过 `guide-library.html` 提供导读与阅读顺序。

## 使用

纯静态 HTML,本地直接打开 `index.html` 或部署到任意静态服务器即可。
