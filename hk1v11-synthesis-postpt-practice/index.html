🔄 0929-30 — G13 打一拍（SHORT+LONG）终版落地 + 放量回归
G13 打一拍两分支终版落地 + 服务器回归闭环（SHORT `df3e7d32` → v2 `4a4cd776` → v3 `16e653e3`；LONG v4.1 `451211a0`）：SHORT = 三件套打一拍（新增 PRE_D/POINT_D/D3 三 FF、桶形/16 比较器/KCODE_REG/装载值切延时域、DATA_ALIGN 切 PRE_D），ICG 使能环（worst −1.31）在 PRE_D 处切断两段各 ≤13 级；LONG = uniform+1 终版（+80bit FF、桶形 {D1,D2}/{D2,D3}、掩码-窗口互锁恢复 + 回波守卫 L-11）。验证链：Qwen×6+GLM×3 九路独立实施收敛 + 6 路对抗评审 + K3 六维终审；服务器回归 A/B 实锤后两层根因修复：层1 DECODE 钥判决同拍交叉比较（新增 DATA_POINT_LAT_D 复原相位）、层2 反重触发掩蔽比较器 lag-1 几何（比较器组拆分：掩蔽吃组合 PRE、K*_FIND 吃 PRE_D）。结果：批量回归 SHORT 59/60（基线转绿、SD_CHOP/FPS 全家族 PASS）、LONG 420b 52/52 + 放量 369/382（96.6%）。回归教育点：增量静态审两轮全过仍漏装载拍瞬态（掩码 select 在 LAT 装载后一拍 stale）——全量审 2/3 判 critical 后 L-11 请回；放量暴露 FAIL 聚类 H3456×CH_SEL4×420b 10 条（50 错 quit 形态，与 v3 病征同款）定责中；CTRL_L_LINE_OVERRIDE 1 例同责。方法论沉淀：打一拍必验"掩码×窗口同拍互锁 + 同拍交叉比较消费者"，静态相对几何推演（正反两向）均不可信，对拍 TB/服务器实跑为终审——已沉淀"重定时三查 + 新旧 RTL 同激励对拍第四关"（rtl-code-review skill 已增维度）。剩余：upsize X4、下次 DC run 验 56 条清零。全档详见 ch15《记忆唤醒》
