每晚复盘（收盘后）

你发： 1. 持仓截图（像 9/27 那样的持仓列表） 2. 交易记录页截图（当日成交明细） 3. 有清仓的话，"已清仓"页截图 4. 收益分析页截图（本月/近三月盈亏、日历、击败分位）——可选，用于收益质量追踪

我做：更新 持仓快照.csv / 成交流水.csv / 账户总览.md / 收益追踪.md，然后输出： 1. 当日盈亏归因：哪些票贡献、哪些拖累，和昨天对比的变化 2. 持仓逐只体检：按你的卖出纪律逐项检查每只（近5日流向、红柱状态、动向比、止损位距离），标出已触发出场信号的 3. 行为统计（随积累）：胜率、盈亏比、平均持仓天数、止损执行率、买入理由兑现率 4. 收益质量（有收益分析截图时）：对上证超额、日胜率、组合波动/指数波动倍数、击败分位变化 5. 新现象 → 记入规律手册"微操校准点"

盘中判定（交易时段）

你发（每只股票 4 张图，尽量同一时点截取）： 1. 日线 K 线：含 MA5/10/20/60、成交量，近 60 根可见 2. 分时图 3. ZJLX 指标副图（主买净额 / 近5日 / 近10日流向） 4. ymz 指标副图（主力资金红柱 / 主动买盘黄柱 / 动向比 / 主力占比）

并说明：是新候选（问能不能买）还是持仓中（问持有还是卖）。

我做：按五步法固定格式输出判定（五步逐项过/不过 + 结论 + 买点类型 + 支撑与硬止损 + 建议仓位），写入 tdx_review/判断记录.md。

判定闭环（规律总结的原料）

每个盘中判定，在之后的晚复盘中回填验证：次日及随后几日走势 vs 判定结论 → 对 / 错 / 待定。 每积累 10~15 个已验证判定（或你说一声"总结"），我更新一版规律手册：反复被验证的信号写进"已固化规律"，失灵的阈值降级或修改，版本号 +0.1。

报告分析模式（进阶）

你发：几千~几万字的完整报告。直接粘贴即可（太长就分几条消息发我拼起来）；也可以存成 txt/md 文件放进工作区的 研报/ 文件夹再告诉我文件名。

我做四步：

  1. 提取：把报告里所有股票扒出来列成候选清单（代码/名称/核心逻辑/关键数据/目标价），报告本身编号存档。
  2. 审稿：逐只核对描述是否合理——
  3. 数据自洽：数字前后矛盾、单位/比例对不上、增速与基数不符
  4. 逻辑完整：利好是否已兑现（利好出尽）、逻辑能否被证伪、假设链哪一环最弱
  5. 话术红旗：绝密/稳赚/翻倍/催促建仓、无风险提示、"深度报告"配合近期暴涨
  6. 公开事实核验：涉及公告/业绩类陈述可尝试联网查证，但以报告原文+你的图为准
  7. 价格位置类描述：一律标"待补图核实"——我看不到实时行情
  8. 初筛：A类（逻辑+数据自洽，值得补图判定）/ B类（纯叙事先观察）/ C类（有硬伤或红旗，直接弃并写明原因）
  9. 补图判定：A类名单给你 → 你补 日线K线+ZJLX+ymz 截图 → 逐只跑五步判定，照常入 tdx_review/判断记录.md

铁律：报告决定"看什么"，五步法决定"买不买"。 报告吹得再好，五步不过就不碰（对应你的原则1：位置决定信号性质）。审稿结论全部记入 研报候选池.md。

边界说明

  • 所有结论立足于"按你的标准"，是决策辅助，不是投资建议；下单永远你决定。
  • 判定质量取决于截图数值完整清晰；缺行先要补图，不猜数值。
  • ETF 等无 L2 数据的品种处于指标盲区，判定会明确标注"盲区"，这类票按你的纪律另行处理。
  • 盘中指标数值是当日实时累计，越接近收盘越可靠；早盘信号天然噪声大（校准点 #4）。
