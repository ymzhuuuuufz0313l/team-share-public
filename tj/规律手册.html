规律手册（持续修订）

目标：随每日复盘与盘中判定积累，把"哪些信号/阈值/纪律真正有效"逐步固化为可执行规律。 当前版本 v0.1 · 2026-09-27 建档

一、当前规则基线（v0.1 = 五步法原版，一字未改）

  • 五步：①位置 ②共振 ③成色 ④累计 ⑤K线。全过→单股≤35%（用户2026-09-27修正：30~35%可接受）；差一步→半仓试探；差两步以上→不碰。
  • 卖出纪律：破买入日最低价无条件走；近5日流向转负至少减半；红柱变矮/翻青/动向比转负离场；价创新高柱不新高→清仓警报。
  • 六条核心原则：位置决定信号性质；价涨钱出=派发；红高滞涨=对倒；涨停日口径失真需次日确认；缩量阴跌回避；近5日流向=生命线。
  • 仓位铁律：别满仓赌；总仓位>85%→买入只提示不执行。单股上限 35%（用户2026-09-27修正：30~35%为可接受区间，原版标准写≤3成）。（注：2026-09-27 实盘总仓位 99.99% 仍超总闸；精智达 37.6% 轻微超限 2.6pct。）

四、完整决策流程（v0.1.1，全部源自原版标准，未新增任何阈值）

出发前：仓位总闸（最高优先级）

  • 总仓位 >85% → 所有买入信号只提示、不建议执行，先修仓位
  • 某只票已 ≥35% → 该票任何加仓信号自动降级为"持有"

A. 候选股：能不能买（五步判定，一票否决优先）

  • 触发任一否决项（大涨50%+/连续涨停/破位下跌；一红一青打架；动向比<1；主力占比≈0；近5日大负加速；阴线/长上影/缩量十字星）→ 不碰，进观察池
  • 无否决、五步全过 → 可买，单股≤35%
  • 无否决、差一步 → 半仓试探（≤1.5成） 三种标准买点（满足才执行，否则继续等）：
  • 突破买：低位横盘 + 双红柱 + 动向比>1.5 + 近5日转正 + 放量阳突破
  • 回调买：强信号后缩量回调不破前低 + 再次翻红黄柱（冰封线"34低吸"图标=量化触发参考，观察口径）
  • 左侧试探：深跌后青柱持续缩短 + 近5日跌幅收窄（冰封线深绿乖离点=深跌量化参考），最小仓位

价格侧辅助（冰封黄白线·观察口径，详见 冰封黄白线-函数解读.md）：QS 多头排列=①位置加分；价在黄线下方/空头排列→①位置判不过；ATR红点≥6档→过热佐证。价格侧不做主判，资金侧一票否决权不变。

B. 持仓股：持有还是卖（按优先级，触发即执行）

  1. 破买入日最低价 / 上移后的止损位 → 无条件清仓
  2. 近5日流向转负 → 至少减半
  3. 红柱逐日变矮 / 翻青 / 动向比转负 → 离场
  4. 价创新高而柱不新高（顶背离）→ 清仓警报
  5. 高位放量滞涨 → 减仓
  6. 以上全未触发 且 近5日流向为正 → 无忧持有，不动
  7. （观察中·校准点#15/#16）价格侧参考：新破白线BX→减仓参考；收盘破黄线HX或白线下穿黄线→离场参考；与第2条同日出现→无条件离场

C. 等待状态

观察池个股每日收盘后快检五步；出现 A 类标准买点才升级为完整判定。

D. 盘中执行规则（校准中）

  • 五步结论以最近收盘数据为底，盘中只回答"现在执行吗"
  • 早盘（11:00 前）信号权重打折；冲高 >4% 后回落 = 假脉冲嫌疑，当日按观望处理
  • 尾盘（14:30 后）信号最可信；涨停日口径失真按原版原则4处理

五、分析风格基线（用户自述 · 2026-09-27，"部分参考"级）

来源：用户此前与他人交流中自述的分析风格。定位：读图顺序与判断习惯的基线，未量化的部分转入校准点 #17~20。

  1. 副图指标优先于价格：ZJLX（主买净额）与 ymz（主力资金/主动买盘/动向比）是核心；MACD 只做趋势确认；K 线形态本身权重低。（衔接说明：五步⑤的 K 线检查保留，但定位为"必要非充分条件"——不过关一票否决，过关不加权）
  2. 资金结构拆解：不只看单日净流入，重点看近5日 vs 近10日对比（加速流入 vs 底子变薄）；以及大单（DDX）与中单的背离
  3. 位置感：区分上方压力带与下方支撑区；任何结论必须落到具体价位（哪里减、哪里守），禁止模糊多空判断
  4. 分层纪律：按价位分批（前高附近减仓）+ 按防守线分批（跌破 X 减 1/4）；信仰仓与机动仓分开管理
  5. "该强不强"是重要信号：大盘大涨它滞涨、借高开放量出货等"行为证据"权重很高（与个股对上证超额同理，下沉到个股级）
